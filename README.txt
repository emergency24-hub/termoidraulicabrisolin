BRISOLIN ETTORE — SITO WEB STATICO
==================================

COME APRIRE IL SITO
- Aprire index.html in un browser oppure caricare la cartella su un hosting statico.
- Non servono framework, npm o un backend.

PAGINE
- index.html          Home
- servizi.html        Panoramica servizi e galleria illustrativa
- idraulica.html      Impianti idraulici
- riscaldamento.html  Riscaldamento
- chi-siamo.html      Presentazione aziendale
- contatti.html       Contatti (nessun modulo)

FILE PRINCIPALI
- config.js           Nome, telefono, indirizzo ed email da modificare in un solo punto.
- script.js           Link dinamici, mappa, menu mobile e anno nel footer.
- style.css           Palette bianco/blu/rosso, stili delle pagine e media query.
- assets/logo.png     Logo originale.
- assets/images/      Le sei fotografie fornite, salvate localmente.

MODIFICHE VELOCI
1. Aprire config.js e cambiare i dati aziendali.
2. Modificare i testi direttamente nei file .html.
3. Modificare colori e layout tramite style.css.
4. Sostituire le immagini in assets/images/ mantenendo lo stesso nome,
   oppure aggiornare l'attributo src nei file HTML.

NOTA EMAIL
"info@Brisolin Ettore" e' il testo provvisorio indicato dal cliente.
Non e' un indirizzo email valido. Il pulsante mailto si attivera' quando
in config.js sara' inserito un indirizzo valido (esempio: info@dominio.it).

FOTO
Le fotografie sono quelle fornite dal cliente. Verificare i diritti d'uso
prima di pubblicare commercialmente il sito. La galleria le presenta come
immagini illustrative, non come interventi realizzati dall'azienda.
